# security-app-practice

## 概要
COACHTECH 教材 Tutorial 10-6「Webセキュリティ ハンズオン」で作成した成果物です。セキュリティを意識したお問い合わせフォームを作成しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- CSRF 保護（`@csrf`）、XSS 対策（Blade の自動エスケープ）

## 学んだこと
- CSRF攻撃の仕組みと保護（CSRFトークン）
- XSS攻撃とその対策

## 動作確認
ブラウザで http://localhost/contact にアクセスし、フォームが表示されることを確認します。入力後、完了画面が表示され、入力内容が表示されていれば成功です。また、必須項目を空欄にして送信すると、バリデーションエラーが表示されることを確認してください。
